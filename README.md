# Biblioteca de Seções do Elementor

Projeto Frontend em React + Vite integrado ao Supabase.

## Scripts Disponíveis

- `npm install`: Instala as dependências.
- `npm run dev`: Inicia o servidor de desenvolvimento.
- `npm run build`: Compila o projeto para produção na pasta `dist/`.

## Hospedagem

Este projeto foi otimizado para ser hospedado no Netlify (ou Vercel/Cloudflare Pages).
Lembre-se de configurar as variáveis de ambiente `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` no painel da sua hospedagem.
